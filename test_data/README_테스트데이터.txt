================================================================================
                        챗봇 테스트 데이터 가이드
================================================================================

본 폴더에는 문서박사 챗봇의 성능을 테스트하기 위한 샘플 데이터가 포함되어 있습니다.

[작성일: 2024.11.20]

================================================================================
                            📁 포함된 파일
================================================================================

1. A과제_AI기반_문서관리시스템.txt
   - A과제(문서관리 시스템) 상세 정보
   - 과제 목적, 참여 인력, 기술 스택, 일정, 예산 등

2. B과제_스마트팩토리_MES시스템.txt
   - B과제(스마트팩토리 MES) 상세 정보
   - 과제 목적, 참여 인력, 기술 스택, 일정, 예산 등

3. 프로젝트_참여자_명단.txt
   - 10명의 프로젝트 참여자 상세 정보
   - 이름, 소속, 역할, 참여 과제, 연락처 등
   - 겸직 인력 정보 포함

4. 2024년_프로젝트_비교분석.txt
   - A과제와 B과제의 종합 비교 분석
   - 기술, 예산, 인력, 난이도, 기대 효과 등 다각도 비교

다음 기준으로 답변을 평가하세요:

✅ 정확성
  - 문서 내용과 일치하는가?
  - 숫자, 날짜, 이름 등이 정확한가?

✅ 완전성
  - 질문에 필요한 모든 정보를 포함하는가?
  - 중요한 내용이 빠지지 않았는가?

✅ 관련성
  - 질문과 관련된 답변인가?
  - 불필요한 정보는 없는가?

✅ 가독성
  - 이해하기 쉽게 정리되어 있는가?
  - 구조화되어 있는가? (목록, 단계 등)

✅ 출처 표시
  - 어떤 문서에서 정보를 가져왔는지 표시되는가?

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
문제 1: 답변이 "관련 정보를 찾을 수 없습니다"
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

원인:
  - 파일이 제대로 업로드되지 않았거나
  - 파일 처리가 완료되지 않았을 수 있습니다

해결:
  1. 관리자 모드 > 자료 업로드 탭에서 파일 목록 확인
  2. "처리 상태"가 "완료"인지 확인
  3. 파일을 다시 업로드 시도


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
문제 2: 답변이 부정확하거나 불완전함
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

                        💡 추가 팁
================================================================================

1. 다양한 질문 방식 시도
   - "A과제의 목적은?" vs "A과제는 왜 시작했어?" vs "A과제 목적"
   - 어떤 표현이 더 정확한 답변을 주는지 비교

2. 복합 질문 테스트
   - "A과제 리더는 누구고 연락처는?"
   - 여러 정보를 한번에 물어볼 수 있는지 테스트

3. 오류 유도 질문
   - "C과제는 뭐야?" (존재하지 않는 과제)
   - 문서에 없는 내용을 물었을 때 어떻게 답하는지 확인

4. 비교 질문
   - "A과제와 B과제 중 뭐가 더 좋아?"
   - 주관적 질문에 어떻게 대응하는지 확인

5. 추상적 질문
   - "프로젝트 성공을 위해 중요한 건?"
   - 문서 내용을 종합하여 답할 수 있는지 테스트
